# 🩺 Diabetes Prediction using Machine Learning

## 📌 Project Overview

This project focuses on predicting whether a person has diabetes or not using Machine Learning classification algorithms.

The dataset contains medical and demographic information of patients. The target variable `Outcome` is used to classify patients into two categories:

- `0` → No Diabetes
- `1` → Diabetes

The project follows a complete Machine Learning workflow including data exploration, visualization, preprocessing, feature selection, model training, model evaluation, cross-validation, and model saving.

---

## 🎯 Objective

The main objective of this project is to build and evaluate Machine Learning classification models that can predict diabetes based on patient-related features.

---

## 📊 Dataset

The dataset contains **768 records** and **9 columns**.

### Features

| Feature | Description |
|---|---|
| Pregnancies | Number of pregnancies |
| Glucose | Plasma glucose concentration |
| BloodPressure | Blood pressure measurement |
| SkinThickness | Skin fold thickness |
| Insulin | Insulin level |
| BMI | Body Mass Index |
| DiabetesPedigreeFunction | Diabetes pedigree function |
| Age | Age of the patient |

### Target

`Outcome`

- `0` → No Diabetes
- `1` → Diabetes

## ⚙️ Machine Learning Workflow

The following steps were performed:

1. Load the dataset
2. Explore the dataset
3. Check missing values
4. Perform exploratory data analysis
5. Split the dataset into training and testing data
6. Apply feature scaling
7. Perform feature selection
8. Train multiple classification models
9. Evaluate the models
10. Perform 5-fold cross-validation
11. Save the trained model
